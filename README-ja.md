# Kong Discovery — 内部レビュー版 v0.1 (Dark)

6パーツ・27ページ＋目次を一つのHTMLにまとめたレビュー用サンプルです。

## ローカルでの開き方

1. ZIPを展開します。
2. kong-discovery-review-dark.html をChrome / Edge等のデスクトップブラウザで開きます。Webサーバーは不要です。
3. 全画面ボタンでプレゼンテーション表示にできます。

CSS・JavaScript・SVG・reveal.jsはHTMLに内包しています。Google Fontsと出典リンクにはネット接続を利用します。フォントが取得できない場合は端末内のフォントに切り替わります。

## 操作

- 目次：6つのストーリーの概要へ移動。
- 左右キー／下部の左右ボタン：横方向に各ストーリーの概要へ移動。
- 上下キー／下部の上下ボタン：同じストーリーの詳細を移動。
- 下部タブ：同じストーリー内のページを直接選択。
- 「概要に戻る」：そのストーリーの概要へ戻る。
- 「目次」：最初の目次へ戻る。
- 図の選択肢：図と説明を切替。実APIやAIモデルへの接続はありません。

## レビューしてほしいこと

- 情報量と読みやすさ、ダイアグラムの分かりやすさ。
- 横の概要／縦の詳細の移動、目次、戻る動作。
- 図の選択・切替とキーボード操作。
- ご利用環境での表示崩れ、全画面表示、ローカルファイルでの操作。

指摘時はパーツ名・ページ番号（例：06.3）・選択状態（Kong / Apigee等）・ブラウザ/OSを添えてください。
