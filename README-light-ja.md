# Kong Discovery — 内部レビュー版 v0.1 (Light)

6パーツ・27ページ＋目次のLight版です。Darkと同じ内容・ページ構成・局所操作を収録しています。比較2パーツと統合版は最終受入前です。

ZIPを展開し、kong-discovery-review-light.html をChrome / Edge等で開きます。Webサーバーは不要です。各パーツのHTMLはparts/にあります。

目次から各概要へ移動し、左右は概要、上下は同じストーリーの詳細です。下部タブでページを選び、終端の「概要に戻る」で同じストーリーの先頭に戻ります。図の選択はローカル表示の切替で、実APIやAIモデルは呼びません。

テーマは生成時にLightへ固定。グレー背景/濃色文字/局所ライム強調を使い、閲覧時のテーマ切替はありません。CSS・JS・SVG・reveal.jsはHTML内包、Google Fontsと出典の閲覧にはネット接続を使います。フォント取得不可時は端末のフォントへ切り替わります。

## レビュー項目

- 図・ラベル・選択状態の読みやすさとライムの強調量。
- 全27ページ、目次、横/縦移動と概要戻り。
- 受取環境での直接ファイル起動・全画面・ブラウザ差。

Kong概要紹介の単体Lightは受入済みv0.3.3を同一byteで保持。追加5個は既存Darkの内容をLightへ展開した初稿です。Markdown指示書・任意ページ差込みの最終仕様はこの配布に含みません。

検証結果と限界はVaultのLight展開記録に保存します。SHA256SUMS-light.txtで同一性を確認できます。reveal.js 6.0.2のMITライセンスはHTML内に保持しています。
