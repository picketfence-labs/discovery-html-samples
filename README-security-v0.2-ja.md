# API・AIセキュリティ Dark v0.2

APIセキュリティ6ページ、AIセキュリティ8ページを含む通し版17ページです。各単独版も同梱しています。

- 通し版: kong-security-review-dark-v0.2.html
- API単独版: api-security-dark-v0.2.html
- AI単独版: ai-security-dark-v0.2.html

HTMLファイルを通常のブラウザで開いてください。下方向へ読み進め、左上の章メニューから各章へ移動できます。図の選択肢はクリックで切り替えられます。テーマはDark固定です。

CSS・JavaScript・SVG・reveal.jsはHTML内に梱包しています。Google Fontsと出典リンクはネットワークを利用します。製品API・IdP・LLMへの接続は行わず、図の切替は説明用の表示です。製品機能は記載した条件・版・構成に依存します。

Pages上のHTMLと同じ内容です。SHA256SUMS-security-v0.2.txtで照合できます。直接ファイルからの表示・全画面・共有先のブラウザ環境は受取側で確認してください。
