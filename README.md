# Discovery HTML samples

[Kong Discovery — Dark review sample](https://picketfence-labs.github.io/discovery-html-samples/)

Six stories, 27 story pages plus a table of contents. The sample is prepared for review; this repository and its Pages site are publicly accessible.

- [Portable HTML](https://picketfence-labs.github.io/discovery-html-samples/kong-discovery-review-dark.html)
- [Download ZIP (HTML, Japanese instructions, manifest and checksum)](https://picketfence-labs.github.io/discovery-html-samples/kong-discovery-review-dark-v0.1.zip)
- [Japanese review instructions](README-ja.md)
- [SHA-256 checksum](SHA256SUMS.txt)

All slide CSS, JavaScript and SVG are bundled into a single HTML. Google Fonts and reference links use the network. No live product APIs or models are called. Theme: Dark, fixed at generation time.

reveal.js 6.0.2 is MIT licensed; its license is included in the HTML. Presentation content and respective marks remain with their owners.

This repository contains delivery artifacts only. Original decks, source notes and authoring workspace are excluded.
